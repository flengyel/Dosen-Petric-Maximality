## Exact endpoints and hypotheses

All statements hold for arbitrary `P : Type u`, normal forms A/B and raw
terms `t₁ t₂ : Reduced.Term P A B`. There is no assumption that their relations
agree. No inhabitant, decidable equality, finite enumeration or freshness
condition on P is required.

`commonAtomicFactor t₁ t₂ : CommonAtomicFactor t₁ t₂` supplies lists ps/qs
with exact equalities

```
ps = t₁.etaLabels ++ t₂.etaLabels
qs = t₁.epsilonLabels ++ t₂.epsilonLabels.
```

These are occurrence lists, not deduplicated sets. Let

```
A′ = AtomicPorts.expand conj A ps
B′ = AtomicPorts.expand disj B qs
a  = ofTerm (AtomicPorts.etaPrefix A ps) : Reduced.Hom A A′
b  = ofTerm (AtomicPorts.epsilonSuffix B qs) : Reduced.Hom B′ B.
```

The record's input/output, before/after and embedA/embedB functions expose
these common objects, arrows and tagged maps. Its fields middle₁/middle₂ are
raw terms A′ → B′, with positive₁/positive₂ membership proofs, and

```
ofTerm t₁ = a ; ofTerm middle₁ ; b
ofTerm t₂ = a ; ofTerm middle₂ ; b.
```

Semicolon executes the left arrow first. Equalities are in the original reduced
syntactic quotient, generated by the unchanged Reduced.Derives and Equation.
No equality after inclusion or interpretation defines that quotient.
Zeros are endomorphisms; no arrow is installed in an arbitrary empty hom-set.

For the common injective embeddings embedA : Occ(A) → Occ(A′) and
embedB : Occ(B) → Occ(B′), both support fields prove, for every u/v,

```
relation middleᵢ u v ↔ ∃ x y,
  u = embedA x ∧ v = embedB y ∧ relation tᵢ x y.
```

Thus the result proves both agreement at embedded original endpoints and
absence of every auxiliary input/output edge. embedded₁/embedded₂ give the
restricted equalities explicitly; relations_equal deduces equality of the
entire middle relations if t₁.relation = t₂.relation. Tags are never collapsed
because their signed literal labels agree.

## Positive fragment and individual factorization

Term.Positive is an inductive predicate with the 19 inherited non-eta/epsilon
constructor schemas, recursively closed under composition and both tensors.
It includes zero endomorphisms. “Positive” refers to arrow constructors;
objects may contain either literal sign and both constants. No separate
quotient or interpretation kernel is introduced.

Term.atomicView covers every raw constructor. It chooses the first atomic
syntactic occurrence, not every subterm with a matching label. AtomicSplit
provides a positive preterm, a typed one-hole context, a postterm and their
quotient equality. Its label equations preserve every repeated occurrence.
The eta/epsilon remainders use the completed contextual g identities and zero
endomorphisms. Each remainder has atomicCount exactly one smaller, as proved
by etaRemainder_lt/epsilonRemainder_lt. Lean checks the well-founded recursion
in atomicFactor; there is no assumed terminating extraction procedure.

AtomicFactor t contains the term's exact eta/epsilon traversal lists, a positive
initial raw middle at its own expanded endpoints, and a factorization equality.
This initial middle is distinguished from a completed common middle.
`supportedAtomicFactor t` inserts both final zero masks, retaining the same
individual lists and proving complete support as well as the quotient equality.

## Shared factors and complete support

The common construction performs one extraction of
`t₁ ∧ t₂ : A ∧ A → B ∧ B`. Its lists are exactly the two traversal lists
concatenated. For that initial positive middle M, form two positive terms

```
n₁ = lift conj (diag A) ps ; M ; lift disj (fst B B) qs
n₂ = lift conj (diag A) ps ; M ; lift disj (snd B B) qs.
```

prefix_natural/suffix_natural and AtomicFactor.remap move the positive diagonal
and projections across the iterated outer factors. The proved product laws
recover t₁/t₂. Hence both n_i already have the same A′/B′ and outer a/b.
This is a single construction with shared data, not two independent existential
factorizations. The source keep/absent padding laws are also proved separately.

No arbitrary permutation is needed: the common concatenated occurrence word
and its left-associated bracketing are fixed before extraction. Composite
reassociation uses existing category/tensor laws, and expand_append records
the object-fold identity. No permutation, deduplication, equality reflection
or implicit endpoint identification is assumed. The implementation proves the
required common endpoint through the stated diagonal/projection method rather
than identifying an arbitrary pair of separately chosen source f_i' terms.

The completed middles are `m_i = mask conj A ps ; n_i ; mask disj B qs`.
Their Positive proofs are fields. prefix_mask/mask_suffix prove that these
explicit zero factors preserve the factorization equations. This does not
by itself prove support. Independently, zeros_relation/mask_relation compute
their full relations from the raw grammar and show precisely which tagged
blocks survive. Combining that calculation with the graph of the outer prefix
and converse graph of the suffix proves masked_support, then support₁/support₂.

Empty lists reduce to identity terms and maps. The embeddings recursively use
first-summand tags, so repeated equal literals remain distinct. If either
original occurrence type is Empty, the support existential has no witnesses;
all completed middle edges then vanish, including auxiliary edges. The theorem
quantifies over all occurrence values and needs no nonemptiness assumption.

## Exact remaining coherence input

PositiveCoherence P is defined as

```
∀ {A B : NormalForm P} (f g : Term P A B),
  f.Positive → g.Positive → f.relation = g.relation → ofTerm f = ofTerm g.
```

Its conclusion is ambient Reduced.Hom equality; it quantifies only over the
explicit eta/epsilon-free raw terms. No premise, axiom or instance of this
proposition is supplied. `faithful_of_positive_coherence` proves the conditional
implication PositiveCoherence P → Reduced.Faithful P: complete support gives
full relation equality of the common middles, the stated premise gives their
arrow equality, and the shared factors give the original equality. Quotient
induction then covers quotient arrows. No raw factorization function is claimed
to descend to quotient arrows.
