## (B) Major weaknesses

No unresolved major defect was confirmed within this scope. Three possible
fatal extensions were tested and excluded:

1. Anchor: report “Selected and fixed positional correspondence”. Failure mode
   false; evidence derivation. A block swap can reverse the order of fixed
   positions. The selected-order proof uses their interval exclusion only.
   selected1_outside is derived after complete transport; it is not used
   circularly to prove the transport. No general order-preserving map is
   asserted. The `[C]`/`[C]` example explicitly transposes fixed tags 0/1.
2. Anchor: report “Exact predecessor and rank equations”. Failure mode
   unsupported_generalization; evidence structural_argument. The selected
   retained endpoint decreases locally while every other same-side fixed
   position has the same two-node rank. This proves neither rank invariance
   under Reduced equality nor all-site decrease in arbitrary proof contexts.
   No terminating rewrite system, Reducibility or Blocked-w claim is made.
3. Anchor: opening/source table and remaining scope. Failure mode
   misuse_of_prior_work / unsupported_generalization; evidence citation and
   structural_argument. The source's broader exchange/absorption argument
   invokes Semilattice Coherence. Only exchanges wholly inside one fixed gap
   or fixed terminal tail are handled here. Cross-selected, multi-gap and
   absorption configurations remain open. A source citation is not counted
   as a Lean proof of these additional cases.

There is no counterexample asserted to the four stated commutations.
