# arXiv source package, manuscript v15

Prepared 1 November 2026. No arXiv upload has occurred.

Upload Dosen-Petric-Maximality-v15-arxiv-source.tar.gz. Its four root members are main.tex, main.bbl,
references_v15.bib and palomar_v15.bib. The archive was independently extracted
and compiled to 16 pages; its layout text matches the manuscript exactly.
Use pdfLaTeX. The included main.bbl supplies the bibliography. To regenerate it,
run pdflatex, bibtex main, then pdflatex twice.

submission-fields.json records proposed fields and file hashes. abstract.txt
contains the exact TeX abstract; comments.txt supplies copyable comments.
Primary category: math.CT; cross-list: math.LO. MSC 2020: Primary 03G30;
Secondary 03F07, 18A32. The author selects an arXiv-supported distribution
license and checks the server preview in the submission account.

V15 adds Appendix D: mathematical statements of the five registered Lean
entry points and their correspondence with relations on arrows. V14 and every
earlier release remain preserved. The seven prior statement bodies, twelve
numbered displays and all preceding diagrams are unchanged.

The supplied Palomar BibTeX is byte-identical to v14 and cites version 1,
source 2e771844077fd8cebfbe365230f13d4dd13a75b1. Version 2 is separately
registered at source 5dbee39bea09539bd130f729e82636419f71f920. Neither source
nor any registered input is changed by this manuscript revision.
