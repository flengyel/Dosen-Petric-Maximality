# V26 arXiv source package

Prepared 13 November 2026; 23 pages.

The archive `Dosen-Petric-Maximality-v26-arxiv-source.tar.gz` contains four root files:
`main.tex`, `main.bbl`, `references_v26.bib`, and `palomar_v26.bib`.
Compile with pdfLaTeX and BibTeX. Include the bibliography files when supplying
the LaTeX source for reading or review.

in Appendix E identifying the dependencies of the inverse and split-comparison
proofs. The Lean sources, theorem statements, bibliography entries, and existing
source hyperlinks are unchanged.
