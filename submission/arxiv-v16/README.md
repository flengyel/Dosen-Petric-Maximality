# arXiv source package, manuscript v16

Prepared 1 November 2026. No arXiv upload has occurred.

Upload Dosen-Petric-Maximality-v16-arxiv-source.tar.gz. Its four root members are main.tex, main.bbl,
references_v16.bib and palomar_v16.bib. The archive was independently extracted
and compiled to 23 pages; its layout text matches the manuscript exactly.
Use pdfLaTeX. The included main.bbl supplies the bibliography. To regenerate it,
run pdflatex, bibtex main, then pdflatex twice.

submission-fields.json records proposed fields and file hashes. abstract.txt
contains the exact TeX abstract; comments.txt supplies copyable comments.
Primary category: math.CT; cross-list: math.LO. MSC 2020: Primary 03G30;
Secondary 03F07, 18A32. The author selects an arXiv-supported distribution
license and checks the server preview in the submission account.

V16 incorporates the seven accepted Lean-to-paper additions. Appendix D
explains how to read a Lean declaration and follows the short maximality proof
through its named steps; Appendix E constructs the isomorphism inverses and
split comparisons. Footnotes and the proof table link to 49 distinct declarations
at the immutable registered version-1 source. V15 and all earlier releases remain.

The supplied Palomar BibTeX is byte-identical to v15 and cites version 1,
source 2e771844077fd8cebfbe365230f13d4dd13a75b1. Version 2 is separately
registered at source 5dbee39bea09539bd130f729e82636419f71f920. Neither source
nor any registered input is changed by this manuscript revision.
